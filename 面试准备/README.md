## 💡 使用技巧

### 知识点学习
1. **理解 > 记忆**：不要死记硬背，理解原理
2. **实践验证**：看完代码必须自己写一遍
3. **总结输出**：用自己的话解释给别人听
4. **定期复习**：使用间隔重复法（1天、3天、7天、15天）

### 算法刷题
1. **先质量后数量**：把一道题的所有解法都搞懂
2. **分类刷题**：按标签分类，一次专注一个类型
3. **限时训练**：模拟真实面试，每题 20-30 分钟
4. **重复刷题**：第一遍看懂，第二遍自己写，第三遍优化
