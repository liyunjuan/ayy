## 8. 常见问题

### Q1: 调研需要多久？
```
快速版：3-5 天（每天 2-3 小时）
完整版：1-2 周（每天 2-3 小时）

建议：先用 3 天快速调研，然后边准备边补充
```

### Q2: 要调研多少家公司？
```
最少：20 家（了解基本情况）
推荐：30-50 家（全面了解）
最多：100 家（过于耗时）

建议：30 家就够了，质量 > 数量
```

### Q3: 调研后发现不符合要求怎么办？
```
1. 找到差距（算法、新技术）
2. 评估时间（是否能在 2-4 周内补上）
3. 降低预期（投递更匹配的岗位）
4. 延后面试（再准备 1-2 个月）
```
