## 1. 加密基础概念

### 1.1 什么是加密？

**加密（Encryption）**：将明文（Plaintext）转换为密文（Ciphertext）的过程

**解密（Decryption）**：将密文转换回明文的过程

```
明文 ──[加密]──> 密文 ──[解密]──> 明文
```

---

### 1.2 加密算法分类

```
加密算法
├── 对称加密（Symmetric Encryption）
│   ├── DES（已过时）
│   ├── 3DES
│   ├── AES ⭐（推荐）
│   └── ChaCha20
├── 非对称加密（Asymmetric Encryption）
│   ├── RSA ⭐（最常用）
│   ├── ECC（椭圆曲线）
│   └── DSA
└── 哈希算法（Hash Function）
    ├── MD5（已不安全）
    ├── SHA-1（已不安全）
    ├── SHA-256 ⭐（推荐）
    ├── SHA-512
    └── bcrypt（密码哈希）
```

---

### 1.3 核心概念对比

| 特性 | 对称加密 | 非对称加密 | 哈希算法 |
|------|---------|-----------|---------|
| **密钥** | 同一个 | 公钥 + 私钥 | 无密钥 |
| **速度** | 快 | 慢（1000倍差距）| 最快 |
| **可逆性** | 可逆 | 可逆 | **不可逆** |
| **用途** | 大量数据加密 | 密钥交换、数字签名 | 数据完整性、密码存储 |
| **密钥长度** | 128/256-bit | 2048/4096-bit | 输出固定长度 |
| **代表算法** | AES | RSA | SHA-256 |

## 2. 对称加密

### 2.1 工作原理

```
发送方                           接收方
  │                               │
  │  ① 共享密钥 K                 │
  │  ←─────────────────────────→  │
  │                               │
  │  ② 明文 M                     │
  │  加密：C = Encrypt(M, K)      │
  │                               │
  │  ③ 密文 C                     │
  │  ─────────────────────────→   │
  │                               │
  │  ④ 解密：M = Decrypt(C, K)    │
```

**核心问题**：密钥如何安全传输？（需要密钥交换协议，如 Diffie-Hellman）

---

### 2.2 AES 加密（推荐）

**AES（Advanced Encryption Standard）**：目前最安全的对称加密算法

**特点**：
- 密钥长度：128、192、256 位
- 分组长度：128 位（16 字节）
- 工作模式：ECB、CBC、CTR、GCM 等

---

#### 前端实现（Web Crypto API）

```javascript
/**
 * AES-GCM 加密
 * @param {string} plaintext - 明文
 * @param {string} password - 密码
 * @returns {Promise<string>} - Base64 编码的密文
 */
async function encryptAES(plaintext, password) {
  // 1. 从密码派生密钥
  const enc = new TextEncoder();
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    enc.encode(password),
    'PBKDF2',
    false,
    ['deriveBits', 'deriveKey']
  );
  
  const key = await crypto.subtle.deriveKey(
    {
      name: 'PBKDF2',
      salt: enc.encode('salt'), // 实际使用随机 salt
      iterations: 100000,
      hash: 'SHA-256'
    },
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['encrypt']
  );
  
  // 2. 生成随机 IV（初始化向量）
  const iv = crypto.getRandomValues(new Uint8Array(12));
  
  // 3. 加密
  const ciphertext = await crypto.subtle.encrypt(
    { name: 'AES-GCM', iv },
    key,
    enc.encode(plaintext)
  );
  
  // 4. 组合 IV 和密文，转为 Base64
  const combined = new Uint8Array(iv.length + ciphertext.byteLength);
  combined.set(iv);
  combined.set(new Uint8Array(ciphertext), iv.length);
  
  return btoa(String.fromCharCode(...combined));
}

/**
 * AES-GCM 解密
 * @param {string} ciphertextBase64 - Base64 编码的密文
 * @param {string} password - 密码
 * @returns {Promise<string>} - 明文
 */
async function decryptAES(ciphertextBase64, password) {
  // 1. 从密码派生密钥（同加密）
  const enc = new TextEncoder();
  const keyMaterial = await crypto.subtle.importKey(
    'raw',
    enc.encode(password),
    'PBKDF2',
    false,
    ['deriveBits', 'deriveKey']
  );
  
  const key = await crypto.subtle.deriveKey(
    {
      name: 'PBKDF2',
      salt: enc.encode('salt'),
      iterations: 100000,
      hash: 'SHA-256'
    },
    keyMaterial,
    { name: 'AES-GCM', length: 256 },
    false,
    ['decrypt']
  );
  
  // 2. 解码 Base64，分离 IV 和密文
  const combined = Uint8Array.from(atob(ciphertextBase64), c => c.charCodeAt(0));
  const iv = combined.slice(0, 12);
  const ciphertext = combined.slice(12);
  
  // 3. 解密
  const plaintext = await crypto.subtle.decrypt(
    { name: 'AES-GCM', iv },
    key,
    ciphertext
  );
  
  return new TextDecoder().decode(plaintext);
}

// 使用示例
(async () => {
  const encrypted = await encryptAES('Hello World', 'my-secret-password');
  console.log('密文:', encrypted);
  
  const decrypted = await decryptAES(encrypted, 'my-secret-password');
  console.log('明文:', decrypted); // Hello World
})();
```

#### Node.js 实现

```javascript
const crypto = require('crypto');

/**
 * AES-256-GCM 加密
 * @param {string} plaintext - 明文
 * @param {string} password - 密码
 * @returns {string} - 密文（格式：iv:authTag:ciphertext，Base64 编码）
 */
function encryptAES(plaintext, password) {
  // 1. 从密码派生密钥（使用 scrypt，更安全）
  const key = crypto.scryptSync(password, 'salt', 32); // 256-bit 密钥
  
  // 2. 生成随机 IV
  const iv = crypto.randomBytes(12); // GCM 推荐 12 字节
  
  // 3. 创建加密器
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
  
  // 4. 加密
  let ciphertext = cipher.update(plaintext, 'utf8', 'hex');
  ciphertext += cipher.final('hex');
  
  // 5. 获取认证标签（GCM 模式）
  const authTag = cipher.getAuthTag();
  
  // 6. 返回：iv:authTag:ciphertext（Base64 编码）
  return Buffer.concat([iv, authTag, Buffer.from(ciphertext, 'hex')])
    .toString('base64');
}

/**
 * AES-256-GCM 解密
 * @param {string} encrypted - 密文（Base64 编码）
 * @param {string} password - 密码
 * @returns {string} - 明文
 */
function decryptAES(encrypted, password) {
  // 1. 解码 Base64
  const buffer = Buffer.from(encrypted, 'base64');
  
  // 2. 分离 IV、authTag 和密文
  const iv = buffer.slice(0, 12);
  const authTag = buffer.slice(12, 28);
  const ciphertext = buffer.slice(28);
  
  // 3. 从密码派生密钥
  const key = crypto.scryptSync(password, 'salt', 32);
  
  // 4. 创建解密器
  const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(authTag);
  
  // 5. 解密
  let plaintext = decipher.update(ciphertext, null, 'utf8');
  plaintext += decipher.final('utf8');
  
  return plaintext;
}

// 使用示例
const encrypted = encryptAES('Hello World', 'my-secret-password');
console.log('密文:', encrypted);

const decrypted = decryptAES(encrypted, 'my-secret-password');
console.log('明文:', decrypted); // Hello World
```

### 2.3 AES 工作模式

| 模式 | 全称 | 特点 | 适用场景 |
|------|------|------|----------|
| **ECB** | Electronic Codebook | 最简单，不安全（相同明文 → 相同密文）| ❌ 不推荐 |
| **CBC** | Cipher Block Chaining | 需要 IV，安全，不能并行加密 | 文件加密 |
| **CTR** | Counter | 需要 IV，可并行，流式加密 | 大文件、流媒体 |
| **GCM** | Galois/Counter Mode | 需要 IV，可并行，带认证 | ⭐ 推荐（TLS 1.3）|

---

#### ECB 的问题（不安全）

```javascript
// ECB 模式：相同明文块 → 相同密文块
const crypto = require('crypto');

function encryptECB(plaintext, key) {
  const cipher = crypto.createCipheriv('aes-256-ecb', key, null);
  return cipher.update(plaintext, 'utf8', 'hex') + cipher.final('hex');
}

const key = crypto.randomBytes(32);
const text1 = 'Hello';
const text2 = 'Hello'; // 相同明文

console.log(encryptECB(text1, key)); // abc123...
console.log(encryptECB(text2, key)); // abc123...（相同密文！）

// 攻击者可以识别模式，不安全
```

---

#### GCM 模式（推荐）

**优势**：
- ✅ 加密 + 认证（AEAD：Authenticated Encryption with Associated Data）
- ✅ 可并行加密
- ✅ 性能好
- ✅ TLS 1.3 默认使用

```javascript
// GCM 提供：
// 1. 机密性（Confidentiality）：加密
// 2. 完整性（Integrity）：认证标签
// 3. 真实性（Authenticity）：防篡改

const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
const authTag = cipher.getAuthTag(); // 认证标签

// 如果密文被篡改，解密时会抛出异常
decipher.setAuthTag(authTag);
```

## 3. 非对称加密

### 3.1 工作原理

```
公钥加密，私钥解密（用于加密）：
发送方                           接收方
  │                               │
  │  ① 获取接收方公钥             │
  │  <─────────────────────────   │
  │  Public Key                   │
  │                               │
  │  ② 用公钥加密明文              │
  │  C = Encrypt(M, PublicKey)    │
  │                               │
  │  ③ 发送密文                   │
  │  ─────────────────────────→   │
  │                               │
  │  ④ 用私钥解密                 │
  │  M = Decrypt(C, PrivateKey)   │

私钥签名，公钥验证（用于签名）：
发送方                           接收方
  │                               │
  │  ① 用私钥签名                 │
  │  Sig = Sign(M, PrivateKey)    │
  │                               │
  │  ② 发送消息 + 签名             │
  │  ─────────────────────────→   │
  │  M, Sig                       │
  │                               │
  │  ③ 用公钥验证签名              │
  │  Verify(M, Sig, PublicKey)    │
```

---

### 3.2 RSA 加密

**特点**：
- 密钥长度：1024、2048、4096 位
- 安全性：基于大数分解难题
- 速度：慢（不适合大数据加密）
- 用途：密钥交换、数字签名

---

#### Node.js 实现

```javascript
const crypto = require('crypto');

/**
 * 生成 RSA 密钥对
 */
function generateKeyPair() {
  const { publicKey, privateKey } = crypto.generateKeyPairSync('rsa', {
    modulusLength: 2048, // 密钥长度
    publicKeyEncoding: {
      type: 'spki',
      format: 'pem'
    },
    privateKeyEncoding: {
      type: 'pkcs8',
      format: 'pem'
    }
  });
  
  return { publicKey, privateKey };
}

/**
 * RSA 加密
 * @param {string} plaintext - 明文
 * @param {string} publicKey - 公钥（PEM 格式）
 * @returns {string} - Base64 编码的密文
 */
function encryptRSA(plaintext, publicKey) {
  const encrypted = crypto.publicEncrypt(
    {
      key: publicKey,
      padding: crypto.constants.RSA_PKCS1_OAEP_PADDING,
      oaepHash: 'sha256'
    },
    Buffer.from(plaintext, 'utf8')
  );
  
  return encrypted.toString('base64');
}

/**
 * RSA 解密
 * @param {string} ciphertext - Base64 编码的密文
 * @param {string} privateKey - 私钥（PEM 格式）
 * @returns {string} - 明文
 */
function decryptRSA(ciphertext, privateKey) {
  const decrypted = crypto.privateDecrypt(
    {
      key: privateKey,
      padding: crypto.constants.RSA_PKCS1_OAEP_PADDING,
      oaepHash: 'sha256'
    },
    Buffer.from(ciphertext, 'base64')
  );
  
  return decrypted.toString('utf8');
}

// 使用示例
const { publicKey, privateKey } = generateKeyPair();

const encrypted = encryptRSA('Hello World', publicKey);
console.log('密文:', encrypted);

const decrypted = decryptRSA(encrypted, privateKey);
console.log('明文:', decrypted); // Hello World
```

#### 前端实现（Web Crypto API）

```javascript
/**
 * 生成 RSA 密钥对
 */
async function generateRSAKeyPair() {
  const keyPair = await crypto.subtle.generateKey(
    {
      name: 'RSA-OAEP',
      modulusLength: 2048,
      publicExponent: new Uint8Array([1, 0, 1]), // 65537
      hash: 'SHA-256'
    },
    true, // 可导出
    ['encrypt', 'decrypt']
  );
  
  return keyPair;
}

/**
 * RSA 加密
 */
async function encryptRSA(plaintext, publicKey) {
  const enc = new TextEncoder();
  const encrypted = await crypto.subtle.encrypt(
    { name: 'RSA-OAEP' },
    publicKey,
    enc.encode(plaintext)
  );
  
  return btoa(String.fromCharCode(...new Uint8Array(encrypted)));
}

/**
 * RSA 解密
 */
async function decryptRSA(ciphertextBase64, privateKey) {
  const ciphertext = Uint8Array.from(atob(ciphertextBase64), c => c.charCodeAt(0));
  
  const decrypted = await crypto.subtle.decrypt(
    { name: 'RSA-OAEP' },
    privateKey,
    ciphertext
  );
  
  return new TextDecoder().decode(decrypted);
}

// 使用示例
(async () => {
  const { publicKey, privateKey } = await generateRSAKeyPair();
  
  const encrypted = await encryptRSA('Hello World', publicKey);
  console.log('密文:', encrypted);
  
  const decrypted = await decryptRSA(encrypted, privateKey);
  console.log('明文:', decrypted); // Hello World
})();
```

### 3.3 RSA 加密大文件（混合加密）

**问题**：RSA 只能加密小数据（2048-bit RSA 最多加密 245 字节）

**解决方案**：混合加密（RSA + AES）

```javascript
/**
 * 混合加密：RSA 加密 AES 密钥，AES 加密数据
 * @param {string} plaintext - 明文（可以很大）
 * @param {string} publicKey - RSA 公钥
 * @returns {object} - { encryptedKey, encryptedData }
 */
function hybridEncrypt(plaintext, publicKey) {
  // 1. 生成随机 AES 密钥
  const aesKey = crypto.randomBytes(32);
  
  // 2. 用 AES 加密数据
  const iv = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv('aes-256-gcm', aesKey, iv);
  let encryptedData = cipher.update(plaintext, 'utf8', 'hex');
  encryptedData += cipher.final('hex');
  const authTag = cipher.getAuthTag();
  
  // 3. 用 RSA 加密 AES 密钥
  const encryptedKey = crypto.publicEncrypt(
    {
      key: publicKey,
      padding: crypto.constants.RSA_PKCS1_OAEP_PADDING
    },
    aesKey
  );
  
  return {
    encryptedKey: encryptedKey.toString('base64'),
    encryptedData: Buffer.concat([iv, authTag, Buffer.from(encryptedData, 'hex')])
      .toString('base64')
  };
}

/**
 * 混合解密
 */
function hybridDecrypt(encryptedKey, encryptedData, privateKey) {
  // 1. 用 RSA 解密 AES 密钥
  const aesKey = crypto.privateDecrypt(
    {
      key: privateKey,
      padding: crypto.constants.RSA_PKCS1_OAEP_PADDING
    },
    Buffer.from(encryptedKey, 'base64')
  );
  
  // 2. 分离 IV、authTag 和密文
  const buffer = Buffer.from(encryptedData, 'base64');
  const iv = buffer.slice(0, 12);
  const authTag = buffer.slice(12, 28);
  const ciphertext = buffer.slice(28);
  
  // 3. 用 AES 解密数据
  const decipher = crypto.createDecipheriv('aes-256-gcm', aesKey, iv);
  decipher.setAuthTag(authTag);
  let plaintext = decipher.update(ciphertext, null, 'utf8');
  plaintext += decipher.final('utf8');
  
  return plaintext;
}

// 使用示例
const { publicKey, privateKey } = generateKeyPair();

const largeText = 'A'.repeat(10000); // 10KB 数据
const { encryptedKey, encryptedData } = hybridEncrypt(largeText, publicKey);

const decrypted = hybridDecrypt(encryptedKey, encryptedData, privateKey);
console.log(decrypted === largeText); // true
```

## 4. 哈希算法

### 4.1 什么是哈希？

**哈希（Hash）**：将任意长度的数据转换为固定长度的摘要

**特点**：
- ✅ 不可逆（单向函数）
- ✅ 确定性（相同输入 → 相同输出）
- ✅ 雪崩效应（微小变化 → 完全不同的输出）
- ✅ 抗碰撞（很难找到两个输入产生相同输出）

```javascript
// 示例
hash('Hello')       // 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
hash('Hello!')      // 334d016f755cd6dc58c53a86e183882f8ec14f52fb05345887c8a5edd42c87b7
hash('hello')       // 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
```

---

### 4.2 常见哈希算法

| 算法 | 输出长度 | 安全性 | 用途 |
|------|---------|--------|------|
| **MD5** | 128-bit (32 hex) | ❌ 已破解 | 文件校验（非安全场景）|
| **SHA-1** | 160-bit (40 hex) | ❌ 已破解 | Git 提交（逐步淘汰）|
| **SHA-256** | 256-bit (64 hex) | ✅ 安全 | ⭐ 推荐（区块链、证书）|
| **SHA-512** | 512-bit (128 hex) | ✅ 安全 | 高安全需求 |
| **bcrypt** | 184-bit | ✅ 安全 | ⭐ 密码存储（带盐 + 慢）|
| **Argon2** | 可变 | ✅ 安全 | ⭐ 密码存储（最新）|

---

### 4.3 SHA-256 实现

#### Node.js

```javascript
const crypto = require('crypto');

/**
 * SHA-256 哈希
 * @param {string} data - 数据
 * @returns {string} - 哈希值（十六进制）
 */
function sha256(data) {
  return crypto.createHash('sha256').update(data).digest('hex');
}

// 使用示例
console.log(sha256('Hello World'));
// a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e

// 文件哈希
const fs = require('fs');
function sha256File(filePath) {
  const data = fs.readFileSync(filePath);
  return crypto.createHash('sha256').update(data).digest('hex');
}
```

---

#### 前端实现（Web Crypto API）

```javascript
/**
 * SHA-256 哈希
 * @param {string} data - 数据
 * @returns {Promise<string>} - 哈希值（十六进制）
 */
async function sha256(data) {
  const encoder = new TextEncoder();
  const dataBuffer = encoder.encode(data);
  
  const hashBuffer = await crypto.subtle.digest('SHA-256', dataBuffer);
  
  // 转为十六进制
  const hashArray = Array.from(new Uint8Array(hashBuffer));
  const hashHex = hashArray.map(b => b.toString(16).padStart(2, '0')).join('');
  
  return hashHex;
}

// 使用示例
(async () => {
  const hash = await sha256('Hello World');
  console.log(hash);
  // a591a6d40bf420404a011733cfb7b190d62c65bf0bcda32b57b277d9ad9f146e
})();
```

### 4.4 密码哈希（bcrypt）

**问题**：SHA-256 太快（1 秒可计算数十亿次），容易被暴力破解

**解决方案**：bcrypt / Argon2（慢哈希 + 自动加盐）

```javascript
const bcrypt = require('bcrypt');

/**
 * 密码哈希
 * @param {string} password - 明文密码
 * @returns {Promise<string>} - 哈希值（包含盐）
 */
async function hashPassword(password) {
  const saltRounds = 10; // 成本因子（越大越慢越安全）
  return await bcrypt.hash(password, saltRounds);
}

/**
 * 密码验证
 * @param {string} password - 明文密码
 * @param {string} hash - 哈希值
 * @returns {Promise<boolean>} - 是否匹配
 */
async function verifyPassword(password, hash) {
  return await bcrypt.compare(password, hash);
}

// 使用示例
(async () => {
  const hash = await hashPassword('myPassword123');
  console.log('哈希:', hash);
  // $2b$10$N9qo8uLOickgx2ZMRZoMye6p8K7n0g8G6N4fA6VH7wZ2W8Z8Z8Z8Z
  
  const isValid = await verifyPassword('myPassword123', hash);
```

## 5. 数字签名

### 5.1 什么是数字签名？

**数字签名（Digital Signature）**：用私钥对数据生成签名，用公钥验证签名

**目的**：
- ✅ 验证数据完整性（未被篡改）
- ✅ 验证数据来源（身份认证）
- ✅ 不可否认性（签名者无法否认）

```
签名流程：
1. 对数据计算哈希
2. 用私钥加密哈希 → 签名
3. 发送：数据 + 签名

验证流程：
1. 对数据计算哈希
2. 用公钥解密签名 → 原始哈希
3. 比较两个哈希是否相同
```

### 5.2 RSA 签名

```javascript
const crypto = require('crypto');

/**
 * 生成 RSA 密钥对（用于签名）
 */
function generateSignKeyPair() {
  const { publicKey, privateKey } = crypto.generateKeyPairSync('rsa', {
    modulusLength: 2048,
    publicKeyEncoding: {
      type: 'spki',
      format: 'pem'
    },
    privateKeyEncoding: {
      type: 'pkcs8',
      format: 'pem'
    }
  });
  
  return { publicKey, privateKey };
}

/**
 * RSA 签名
 * @param {string} data - 数据
 * @param {string} privateKey - 私钥
 * @returns {string} - Base64 编码的签名
 */
function signRSA(data, privateKey) {
  const sign = crypto.createSign('SHA256');
  sign.update(data);
  sign.end();
  
  const signature = sign.sign(privateKey);
  return signature.toString('base64');
}

/**
 * RSA 验证签名
 * @param {string} data - 数据
 * @param {string} signature - Base64 编码的签名
 * @param {string} publicKey - 公钥
 * @returns {boolean} - 是否有效
 */
function verifyRSA(data, signature, publicKey) {
  const verify = crypto.createVerify('SHA256');
  verify.update(data);
  verify.end();
  
  return verify.verify(publicKey, Buffer.from(signature, 'base64'));
}

// 使用示例

console.log('验证:', isValid); // true
```

```javascript
const crypto = require('crypto');

 * 生成 API 签名
 * @param {object} params - 请求参数
 * @param {string} appSecret - 应用密钥

 */
function generateSignature(params, appSecret) {
  // 1. 参数排序
  const sortedKeys = Object.keys(params).sort();
  
  // 2. 拼接字符串
  const str = sortedKeys
    .map(key => `${key}=${params[key]}`)
```

### 7.3 数据库字段加密

```javascript
const crypto = require('crypto');

// 加密密钥（应存储在环境变量中）
const ENCRYPTION_KEY = process.env.DB_ENCRYPTION_KEY; // 32 字节
const ALGORITHM = 'aes-256-gcm';

/**
 * 加密数据库字段
 */
function encryptField(plaintext) {
  const iv = crypto.randomBytes(12);
  const cipher = crypto.createCipheriv(ALGORITHM, ENCRYPTION_KEY, iv);
  
  let encrypted = cipher.update(plaintext, 'utf8', 'hex');
  encrypted += cipher.final('hex');
  
  const authTag = cipher.getAuthTag();
  
  // 返回：iv:authTag:ciphertext
  return Buffer.concat([iv, authTag, Buffer.from(encrypted, 'hex')])
    .toString('base64');
}

/**
 * 解密数据库字段
 */
function decryptField(encrypted) {
  const buffer = Buffer.from(encrypted, 'base64');
  
  const iv = buffer.slice(0, 12);
  const authTag = buffer.slice(12, 28);
  const ciphertext = buffer.slice(28);
  
  const decipher = crypto.createDecipheriv(ALGORITHM, ENCRYPTION_KEY, iv);
  decipher.setAuthTag(authTag);
  
  let decrypted = decipher.update(ciphertext, null, 'utf8');
  decrypted += decipher.final('utf8');
  
  return decrypted;
}

// 数据模型中使用

    return await db.query('INSERT INTO users SET ?', encryptedData);
  }
  
  static async findById(id) {
    const [users] = await db.query('SELECT * FROM users WHERE id = ?', [id]);
    
    if (users.length === 0) return null;
    
    // 解密敏感字段
    const user = users[0];
    return {
      ...user,
      email: decryptField(user.email),

  }
}
```

### 8.1 JWT（JSON Web Token）

**结构**：
```
JWT = Header.Payload.Signature

Header（Base64）：{ "alg": "HS256", "typ": "JWT" }
Payload（Base64）：{ "userId": 1, "exp": 1640995200 }
Signature（HMAC-SHA256）：HMACSHA256(Header.Payload, secret)
```

**实现**：
```javascript
const crypto = require('crypto');

/**
 * 生成 JWT
 */
function generateJWT(payload, secret) {
  // 1. Header
  const header = {
    alg: 'HS256',
    typ: 'JWT'
  };
  
  const encodedHeader = base64urlEncode(JSON.stringify(header));
  
  // 2. Payload
  const encodedPayload = base64urlEncode(JSON.stringify(payload));
  
  // 3. Signature
  const data = `${encodedHeader}.${encodedPayload}`;
  const signature = crypto
    .createHmac('sha256', secret)
    .update(data)
    .digest('base64url');
  
  return `${data}.${signature}`;
}

/**
 * 验证 JWT
 */
function verifyJWT(token, secret) {
  const [encodedHeader, encodedPayload, signature] = token.split('.');
  
  // 1. 验证签名
  const data = `${encodedHeader}.${encodedPayload}`;
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(data)
    .digest('base64url');
  
  if (signature !== expectedSignature) {
    throw new Error('签名验证失败');
  }
  
  // 2. 解码 Payload
  const payload = JSON.parse(base64urlDecode(encodedPayload));
  
  // 3. 检查过期时间
  if (payload.exp && payload.exp < Date.now() / 1000) {
    throw new Error('Token 已过期');
  }
  
  return payload;
}

// 辅助函数
function base64urlEncode(str) {
  return Buffer.from(str)
    .toString('base64')
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=/g, '');
}

function base64urlDecode(str) {
  str = str.replace(/-/g, '+').replace(/_/g, '/');
  return Buffer.from(str, 'base64').toString('utf8');
}

// 使用
const payload = {
  userId: 1,
  username: 'alice',
  exp: Math.floor(Date.now() / 1000) + 3600 // 1 小时后过期
};

const token = generateJWT(payload, 'my-secret-key');
console.log('JWT:', token);

const decoded = verifyJWT(token, 'my-secret-key');
console.log('Payload:', decoded);
```

### 8.4 区块链（简化版）

```javascript
const crypto = require('crypto');

class Block {
  constructor(index, timestamp, data, previousHash = '') {
    this.index = index;
    this.timestamp = timestamp;
    this.data = data;
    this.previousHash = previousHash;
    this.nonce = 0;
    this.hash = this.calculateHash();
  }
  
  calculateHash() {
    return crypto
      .createHash('sha256')
      .update(
        this.index +
        this.timestamp +
        JSON.stringify(this.data) +
        this.previousHash +
        this.nonce
      )
      .digest('hex');
  }
  
  // 工作量证明（Proof of Work）
  mineBlock(difficulty) {
    const target = '0'.repeat(difficulty);
    
    while (this.hash.substring(0, difficulty) !== target) {
      this.nonce++;
      this.hash = this.calculateHash();
    }
    
    console.log(`区块挖掘完成: ${this.hash}`);
  }
}

class Blockchain {
  constructor() {
    this.chain = [this.createGenesisBlock()];
    this.difficulty = 4; // 难度（前 4 位为 0）
  }
  
  createGenesisBlock() {
    return new Block(0, Date.now(), 'Genesis Block', '0');
  }
  
  getLatestBlock() {
    return this.chain[this.chain.length - 1];
  }
  
  addBlock(newBlock) {
    newBlock.previousHash = this.getLatestBlock().hash;
    newBlock.mineBlock(this.difficulty);
    this.chain.push(newBlock);
  }
  
  isChainValid() {
    for (let i = 1; i < this.chain.length; i++) {
      const currentBlock = this.chain[i];
      const previousBlock = this.chain[i - 1];
      
      // 验证哈希
      if (currentBlock.hash !== currentBlock.calculateHash()) {
        return false;
      }
      
      // 验证链接
      if (currentBlock.previousHash !== previousBlock.hash) {
        return false;
      }
    }
    
    return true;
  }
}

// 使用
const blockchain = new Blockchain();

console.log('挖掘区块 1...');
blockchain.addBlock(new Block(1, Date.now(), { amount: 100 }));

console.log('挖掘区块 2...');
blockchain.addBlock(new Block(2, Date.now(), { amount: 50 }));

console.log('区块链有效性:', blockchain.isChainValid());
console.log(JSON.stringify(blockchain, null, 2));
```

```javascript
function verifySecureRequest(request, secret, maxAge = 300000) {
  const { signature, timestamp, nonce, ...data } = request;
  
  // 1. 检查时间戳（5 分钟内有效）
  if (Date.now() - timestamp > maxAge) {
    throw new Error('请求已过期');
  }
  
  // 2. 检查 nonce（防止重放）
  if (usedNonces.has(nonce)) {
    throw new Error('Nonce 已使用');
  }
  usedNonces.add(nonce);
  
  // 3. 验证签名
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(JSON.stringify({ timestamp, nonce, ...data }))
    .digest('hex');
  
  if (!crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  )) {
    throw new Error('签名验证失败');
  }
  
  return data;
}

// 使用
const usedNonces = new Set();

const request = generateSecureRequest({ action: 'transfer', amount: 100 }, 'secret');
const data = verifySecureRequest(request, 'secret');
```

### 9.5 密码策略

```javascript
/**
 * 密码强度检查
 */
function checkPasswordStrength(password) {
  const checks = {
    length: password.length >= 8,
    uppercase: /[A-Z]/.test(password),
    lowercase: /[a-z]/.test(password),
    number: /[0-9]/.test(password),
    special: /[!@#$%^&*(),.?":{}|<>]/.test(password)
  };
  
  const score = Object.values(checks).filter(Boolean).length;
  
  return {
    score,
    level: score < 3 ? 'weak' : score < 5 ? 'medium' : 'strong',
    checks
  };
}

/**
 * 密码过期策略
 */
class PasswordPolicy {
  constructor() {
    this.maxAge = 90 * 24 * 60 * 60 * 1000; // 90 天
    this.historySize = 5; // 记住最近 5 个密码
  }
  
  async changePassword(userId, newPassword, oldPasswords) {
    // 1. 检查密码强度
    const strength = checkPasswordStrength(newPassword);
    if (strength.level === 'weak') {
      throw new Error('密码强度不足');
    }
    
    // 2. 检查是否与旧密码重复
    for (const oldHash of oldPasswords) {
      if (await bcrypt.compare(newPassword, oldHash)) {
        throw new Error('不能使用最近使用过的密码');
      }
    }
    
    // 3. 哈希新密码
    const newHash = await bcrypt.hash(newPassword, 10);
    
    // 4. 更新数据库
    await db.query(
      'UPDATE users SET password = ?, password_changed_at = NOW() WHERE id = ?',
      [newHash, userId]
    );
    
    // 5. 记录密码历史
    await db.query(
      'INSERT INTO password_history (user_id, password) VALUES (?, ?)',
      [userId, newHash]
    );
  }
  
  async checkPasswordExpired(userId) {
    const [rows] = await db.query(
      'SELECT password_changed_at FROM users WHERE id = ?',
      [userId]
    );
    
    const changedAt = new Date(rows[0].password_changed_at);
    return Date.now() - changedAt.getTime() > this.maxAge;
  }
}
```

## 10. 面试高频问答

### Q1: 对称加密和非对称加密有什么区别？

**答案**：

| 特性 | 对称加密 | 非对称加密 |
|------|---------|-----------|
| **密钥** | 同一个密钥加密和解密 | 公钥加密，私钥解密 |
| **速度** | 快（1 GB/s）| 慢（1 MB/s）|
| **密钥长度** | 128/256-bit | 2048/4096-bit |
| **密钥分发** | 困难（需要安全通道）| 简单（公钥可公开）|
| **用途** | 大量数据加密 | 密钥交换、数字签名 |
| **代表算法** | AES、DES | RSA、ECC |

**实际应用**：
- HTTPS = RSA（交换密钥）+ AES（加密数据）
- 文件加密 = RSA（加密 AES 密钥）+ AES（加密文件）

---

### Q2: 什么是哈希？哈希和加密有什么区别？

**答案**：

**哈希**：
- 将任意长度数据转换为固定长度摘要
- **不可逆**（单向函数）
- 用途：数据完整性、密码存储、数字签名

**加密**：
- 将明文转换为密文
- **可逆**（可解密）
- 用途：数据保密

```javascript
// 哈希（不可逆）
const hash = sha256('password123'); // e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
// 无法从哈希值还原出 "password123"

// 加密（可逆）
const encrypted = encrypt('password123', key); // a1b2c3d4...
const decrypted = decrypt(encrypted, key); // password123
```

---

### Q3: 为什么不能用 MD5/SHA-1 存储密码？

**答案**：

**问题**：
1. **已被破解**：可以找到碰撞（两个不同输入产生相同哈希）
2. **太快**：1 秒可计算数十亿次，容易被暴力破解
3. **彩虹表攻击**：预计算常见密码的哈希值，快速查表破解

```javascript
// MD5 破解示例（彩虹表）
const md5Hash = '5f4dcc3b5aa765d61d8327deb882cf99';
// 查询彩虹表 → 原密码是 "password"
```

**推荐方案**：
- ✅ bcrypt（慢哈希 + 自动加盐）
- ✅ Argon2（最新推荐）
- ✅ PBKDF2（标准算法）

```javascript
// bcrypt：自动加盐 + 慢哈希
const hash = await bcrypt.hash('password123', 10);
// $2b$10$N9qo8uLOickgx2ZMRZoMye6p8K7n0g8G6N4fA6VH7wZ2W8Z8Z8Z8Z
```

### Q4: 什么是数字签名？如何工作？

**答案**：

**数字签名**：用私钥对数据生成签名，用公钥验证签名

**流程**：
```
签名：
1. 对数据计算哈希
2. 用私钥加密哈希 → 签名
3. 发送：数据 + 签名

验证：
1. 对数据计算哈希
2. 用公钥解密签名 → 原始哈希
3. 比较两个哈希是否相同
```

**代码示例**：
```javascript
// 签名
const signature = signRSA('Hello World', privateKey);

// 验证
const isValid = verifyRSA('Hello World', signature, publicKey);
```

**应用场景**：
- 软件签名（验证软件未被篡改）
- 证书签名（CA 签名网站证书）
- 区块链交易（验证交易合法性）

---

### Q5: HTTPS 中如何同时使用对称加密和非对称加密？

**答案**：

**混合加密方案**：
```
1. TLS 握手（非对称加密）：
   - 客户端生成随机对称密钥
   - 用服务器公钥加密对称密钥
   - 发送给服务器
   - 服务器用私钥解密，获得对称密钥

2. 数据传输（对称加密）：
   - 双方使用协商好的对称密钥
   - 用 AES 加密所有通信数据
```

**为什么这样设计**：
- 非对称加密安全（密钥分发），但慢
- 对称加密快，但密钥分发困难
- 组合使用：用非对称加密传输对称密钥，用对称加密传输数据

---

### Q6: 什么是盐（Salt）？为什么需要加盐？

**答案**：

**盐（Salt）**：加密前添加的随机字符串

**作用**：
- 防止彩虹表攻击
- 相同密码产生不同哈希值

```javascript
// 不加盐（不安全）
const hash1 = md5('password123'); // 5f4dcc3b5aa765d61d8327deb882cf99
const hash2 = md5('password123'); // 5f4dcc3b5aa765d61d8327deb882cf99
// 相同密码 → 相同哈希，容易被识别

// 加盐（安全）
const salt1 = generateSalt();
const hash1 = sha256('password123' + salt1); // a1b2c3...
const salt2 = generateSalt();
const hash2 = sha256('password123' + salt2); // x9y8z7...
// 相同密码 → 不同哈希
```

**bcrypt 自动加盐**：
```javascript
const hash = await bcrypt.hash('password123', 10);
// $2b$10$N9qo8uLOickgx2ZMRZoMye... （盐已包含在哈希中）
```

### Q7: 如何安全地传输密码？

**答案**：

**方案 1：HTTPS（推荐）**
```javascript
// 前端
fetch('https://api.example.com/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    username: 'alice',
    password: 'password123' // HTTPS 自动加密
  })

```

**方案 2：前端 RSA 加密 + HTTPS**
```javascript
// 前端
const encrypted = await encryptRSA('password123', serverPublicKey);

fetch('https://api.example.com/login', {
  method: 'POST',
  body: JSON.stringify({
    username: 'alice',
    password: encrypted // 双重加密
  })

// 后端
const password = decryptRSA(encrypted, privateKey);
```

**❌ 不要这样做**：
- HTTP 明文传输密码
- 前端哈希密码（无法防止重放攻击）

### Q8: JWT 如何保证安全？

**答案**：

**JWT 安全机制**：
```
JWT = Header.Payload.Signature

Signature = HMAC-SHA256(Header.Payload, secret)
```

**安全措施**：
1. **签名验证**：防止篡改
```javascript
if (signature !== expectedSignature) {
  throw new Error('Token 已被篡改');
}
```

2. **过期时间**：防止永久有效
```javascript
if (payload.exp < Date.now() / 1000) {
  throw new Error('Token 已过期');
}
```

3. **HTTPS 传输**：防止窃听

4. **HttpOnly Cookie**：防止 XSS 窃取
```javascript
res.cookie('token', jwt, { httpOnly: true, secure: true });
```

**注意**：
- ❌ Payload 是 Base64 编码，不是加密（任何人都能解码）
- ❌ 不要在 Payload 中存储敏感信息（密码、银行卡号）

### Q9: 如何防止暴力破解？

**答案**：

**1. 限制登录次数**
```javascript
const loginAttempts = new Map();

async function login(username, password) {
  const key = `login:${username}`;
  const attempts = loginAttempts.get(key) || 0;
  
  if (attempts >= 5) {
    throw new Error('登录次数过多，请 30 分钟后再试');
  }
  
  // 验证密码
  const isValid = await verifyPassword(username, password);
  
  if (!isValid) {
    loginAttempts.set(key, attempts + 1);
    setTimeout(() => loginAttempts.delete(key), 30 * 60 * 1000);
    throw new Error('密码错误');
  }
  
  loginAttempts.delete(key);
  return generateToken(username);
}
```

**2. 验证码**
```javascript
// 3 次失败后要求验证码
if (attempts >= 3) {
  if (!verifyCaptcha(captcha)) {
    throw new Error('验证码错误');
  }
}
```

**3. 账户锁定**
```javascript
if (attempts >= 10) {
  await lockAccount(username, 24 * 60 * 60 * 1000); // 锁定 24 小时
}
```

**4. 使用慢哈希（bcrypt）**
```javascript
// bcrypt 本身就很慢，1 秒只能验证约 10 次
const isValid = await bcrypt.compare(password, hash);
```

### Q10: 前端加密有意义吗？

**答案**：

**有限意义**：

**✅ 有意义的场景**：
- HTTPS 不可用时（极少见）
- 端到端加密（服务器也无法解密）
- 本地数据加密（localStorage）

**❌ 意义不大的场景**：
- 已经使用 HTTPS（HTTPS 本身就加密）
- 防止服务器看到密码（服务器需要验证密码）

**核心问题**：
```javascript
// 前端代码是公开的，密钥无处可藏
const publicKey = '...'; // 攻击者也能看到

// 即使前端加密，攻击者可以：
// 1. 直接复制前端加密代码
// 2. 用相同方式加密数据
// 3. 发送加密后的数据
```

**推荐方案**：
- 传输层：HTTPS（必须）
- 存储层：后端加密（数据库字段加密）
- 密码：bcrypt 哈希
- 敏感操作：2FA（双因素认证）

## 11. 总结

### 11.1 核心要点

| 知识点 | 要点 |
|-------|------|
| **对称加密** | 同一密钥，快速，AES-GCM 推荐 |
| **非对称加密** | 公钥私钥，慢，用于密钥交换和签名 |
| **哈希算法** | 不可逆，SHA-256 推荐，密码用 bcrypt |
| **数字签名** | 私钥签名，公钥验证，保证完整性和真实性 |
| **混合加密** | RSA 传输密钥，AES 加密数据（HTTPS 原理）|
| **密码存储** | bcrypt/Argon2，自动加盐，慢哈希 |
| **密钥管理** | 环境变量，定期轮换，分级管理 |
