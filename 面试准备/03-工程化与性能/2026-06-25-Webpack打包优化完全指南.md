## Webpack基础

### 核心概念

```javascript
// webpack.config.js
module.exports = {
  // 1. 入口（Entry）- 构建的起点
  entry: './src/index.js',
  
  // 2. 输出（Output）- 打包后文件的位置
  output: {
    path: path.resolve(__dirname, 'dist'),
    filename: 'bundle.js',
  },
  
  // 3. Loader - 转换非JS文件
  module: {
    rules: [
      {
        test: /\.css$/,
        use: ['style-loader', 'css-loader'],
      },
    ],
  },
  
  // 4. Plugin - 扩展功能
  plugins: [
    new HtmlWebpackPlugin({
      template: './src/index.html',
    }),
  ],
  
  // 5. Mode - 环境模式
  mode: 'production', // 或 'development'
};
```

### 构建流程

```
1. 初始化参数
   ↓
2. 开始编译（创建Compiler对象）
   ↓
3. 确定入口（根据entry配置）
   ↓
4. 编译模块（从入口递归解析依赖）
   ↓
5. 完成模块编译（使用Loader转换）
   ↓
6. 输出资源（根据依赖关系组装成Chunk）
   ↓
7. 输出完成（将Chunk写入文件系统）
```

### 1. 持久化缓存（最有效）⭐⭐⭐⭐⭐

```javascript

  cache: {

  },
```

### 4. DLL预编译 ⭐⭐⭐

**原理：**将不常变化的第三方库预先编译打包，避免每次都重新编译。

**步骤1：创建DLL配置**

```javascript
// webpack.dll.config.js
const path = require('path');
const webpack = require('webpack');

module.exports = {
  mode: 'production',
  entry: {
    vendor: ['react', 'react-dom', 'lodash'],
  },
  output: {
    path: path.resolve(__dirname, 'dll'),
    filename: '[name].dll.js',
    library: '[name]_library',
  },
  plugins: [
    new webpack.DllPlugin({
      name: '[name]_library',
      path: path.resolve(__dirname, 'dll/[name]-manifest.json'),
    }),
  ],
};
```

**步骤2：生成DLL文件**

```bash
webpack --config webpack.dll.config.js
```

**步骤3：在主配置中引用**

```javascript
// webpack.config.js
const webpack = require('webpack');
const AddAssetHtmlPlugin = require('add-asset-html-webpack-plugin');

module.exports = {
  plugins: [
    // 引用DLL manifest
    new webpack.DllReferencePlugin({
      manifest: require('./dll/vendor-manifest.json'),
    }),
    
    // 将DLL文件注入HTML
    new AddAssetHtmlPlugin({
      filepath: path.resolve(__dirname, 'dll/*.dll.js'),
    }),
  ],
};

// 效果：
// 使用DLL前：120s
// 使用DLL后：35s（提升 3.4倍）
```

### 1. 代码分割（Code Splitting）⭐⭐⭐⭐⭐

**入口分割：**

```javascript
module.exports = {
  entry: {
    main: './src/index.js',
    vendor: './src/vendor.js',
  },
};
```

**动态导入（推荐）：**

```javascript
// React懒加载
import React, { lazy, Suspense } from 'react';

const HomePage = lazy(() => import('./pages/Home'));
const AboutPage = lazy(() => import('./pages/About'));

function App() {
  return (
    <Suspense fallback={<div>Loading...</div>}>
      <Routes>
        <Route path="/" element={<HomePage />} />
        <Route path="/about" element={<AboutPage />} />
      </Routes>
    </Suspense>
  );
}

// Webpack魔法注释
import(
  /* webpackChunkName: "my-chunk" */
  /* webpackPrefetch: true */
  './module'
);
```

**SplitChunksPlugin（自动分割）：**

```javascript
module.exports = {
  optimization: {
    splitChunks: {
      chunks: 'all', // 对所有chunk生效
      minSize: 20000, // 最小20KB才分割
      maxSize: 244000, // 尝试分割超过244KB的chunk
      minChunks: 1, // 至少被引用1次
      maxAsyncRequests: 30, // 最大异步请求数
      maxInitialRequests: 30, // 最大初始请求数
      
      cacheGroups: {
        // 提取第三方库
        vendor: {
          test: /[\\/]node_modules[\\/]/,
          name: 'vendors',
          priority: 10,
        },
        
        // 提取公共模块
        common: {
          minChunks: 2,
          name: 'common',
          priority: 5,
          reuseExistingChunk: true,
        },
        
        // 提取React相关
        react: {
          test: /[\\/]node_modules[\\/](react|react-dom)[\\/]/,
          name: 'react',
          priority: 20,
        },
      },
    },
  },
};

// 效果：
// 优化前：main.js 2.5MB
// 优化后：
//   main.js 200KB
//   vendors.js 1.8MB
//   common.js 300KB
//   react.js 500KB
```

### 2. Tree Shaking ⭐⭐⭐⭐⭐

**原理：**移除未使用的代码（Dead Code Elimination）

**配置：**

```javascript
module.exports = {
  mode: 'production', // production模式自动开启
  optimization: {
    usedExports: true, // 标记未使用的导出
    minimize: true,    // 压缩代码
  },
};
```

**package.json配置：**

```json
{
  "sideEffects": false
}

// 或指定有副作用的文件
{
  "sideEffects": [
    "*.css",
    "*.scss",
    "./src/polyfills.js"
  ]
}
```

**使用ES6模块：**

```javascript
// ✅ ES6模块（支持Tree Shaking）
import { add } from './math';

// ❌ CommonJS（不支持Tree Shaking）
const { add } = require('./math');
```

**效果示例：**

```javascript
// utils.js
export function add(a, b) { return a + b; }
export function sub(a, b) { return a - b; }
export function mul(a, b) { return a * b; }

// main.js
import { add } from './utils';
console.log(add(1, 2));

// 打包后只包含add函数，sub和mul被移除
```

| **cheap-module** | + | ++ | ❌ | 原始源代码 |
| **source-map** | - | - | ✅ | 原始源代码 |
| **eval-source-map** | - | + | ❌ | 原始源代码 |

### 2. Gzip/Brotli压缩 ⭐⭐⭐⭐

```javascript
const CompressionPlugin = require('compression-webpack-plugin');

  plugins: [

      algorithm: 'gzip',
      test: /\.(js|css|html|svg)$/,

    // Brotli压缩（更优）

// 效果：
// 原始文件：main.js 500KB

// Brotli后：main.js.br 120KB（减少76%）
```

## Webpack vs Vite

### 原理对比

**Webpack（Bundle-based）：**
```
开发环境：
  启动 → 打包所有模块 → 启动服务器 → 浏览器请求
  修改 → 重新打包 → HMR更新

生产环境：
  构建 → 打包压缩 → 输出bundle
```

**Vite（ESM-based）：**
```
开发环境：
  启动 → 预构建依赖 → 启动服务器 → 按需编译
  修改 → 只编译修改文件 → HMR更新

生产环境：
  构建 → Rollup打包 → 输出bundle
```

### 性能对比

| 项目 | Webpack | Vite | 差异 |
|------|---------|------|------|
| **冷启动** | 60s | 2s | 30倍 |
| **热更新** | 5s | 50ms | 100倍 |
| **生产构建** | 120s | 30s | 4倍 |
| **开发体验** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | 极大提升 |

### 选择建议

**选择Webpack：**
- 老项目（迁移成本高）
- 需要特定Webpack插件
- 需要兼容老浏览器（IE11）
- 复杂的构建需求

**选择Vite：**
- 新项目
- 追求开发体验
- 现代浏览器环境
- Vue/React等现代框架

### Q5: Tree Shaking原理是什么？

**答案：**

**原理：**
Tree Shaking是基于ES6模块的静态分析，移除未使用的代码（Dead Code Elimination）。

**为什么需要ES6模块：**
```javascript
// ES6模块（静态分析）
import { add } from './math'; // 编译时确定依赖

// CommonJS（动态加载）
const math = require('./math'); // 运行时确定依赖
```

**工作流程：**
```
1. 标记阶段（usedExports）
   分析所有导出，标记哪些被使用

2. 删除阶段（minimize）
   压缩工具（Terser）删除未使用代码

3. 副作用处理（sideEffects）
   保留有副作用的代码
```

**实现条件：**
1. 使用ES6模块语法
2. mode: 'production'
3. package.json配置sideEffects

**配置：**
```javascript
// webpack.config.js
module.exports = {
  mode: 'production',
  optimization: {
    usedExports: true,  // 标记未使用导出
    minimize: true,     // 删除死代码
  },
};

// package.json
{
  "sideEffects": false
  // 或
  "sideEffects": ["*.css", "*.scss"]
}
```

**示例：**
```javascript
// math.js
export function add(a, b) { return a + b; }
export function sub(a, b) { return a - b; }
export function mul(a, b) { return a * b; }

// main.js
import { add } from './math';
console.log(add(1, 2));

// 打包后只包含add函数
// sub和mul被Tree Shaking移除
```

**注意事项：**
- CSS导入有副作用（需标记）
- polyfill有副作用（需标记）
- 第三方库需支持ES6模块
