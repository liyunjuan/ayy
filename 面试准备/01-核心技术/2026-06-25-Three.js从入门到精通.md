## Three.js简介

### 什么是Three.js？

Three.js是一个基于WebGL的JavaScript 3D库，封装了WebGL的复杂API，提供了简单易用的高层接口。

**核心特点：**
- ✅ 基于WebGL，GPU加速
- ✅ 丰富的内置几何体和材质
- ✅ 完整的光照和阴影系统
- ✅ 动画和骨骼系统
- ✅ 后处理特效
- ✅ 活跃的社区和生态

**版本说明：**
```javascript
// 当前最新版本（2026）
import * as THREE from 'three';  // r160+

// 兼容性好的稳定版本
// r150+（推荐生产环境）
```

### Three.js vs 原生WebGL

| 对比项 | 原生WebGL | Three.js |
|--------|-----------|----------|
| **代码量** | 绘制立方体 ~300行 | ~30行 |
| **学习曲线** | 陡峭（需要图形学基础） | 平缓 |
| **开发效率** | 低 | 高 |
| **性能** | 极致优化潜力 | 略低（封装损耗） |
| **适用场景** | 特殊效果、极致性能 | 通用3D场景 |

**关系：**
```
Three.js (高层封装)
    ↓ 使用
WebGL (底层API)
    ↓ 基于
OpenGL ES 2.0/3.0
    ↓ 运行在
GPU硬件
```

## 核心概念

### Three.js核心三要素

```javascript
// 1. 场景（Scene）- 容器，包含所有对象
const scene = new THREE.Scene();

// 2. 相机（Camera）- 观察者视角
const camera = new THREE.PerspectiveCamera(75, width/height, 0.1, 1000);

// 3. 渲染器（Renderer）- 将场景渲染到画布
const renderer = new THREE.WebGLRenderer();
```

### 完整渲染流程

```
创建场景（Scene）
    ↓
添加相机（Camera）
    ↓
添加光源（Light）
    ↓
添加物体（Mesh = Geometry + Material）
    ↓
创建渲染器（Renderer）
    ↓
渲染循环（Animation Loop）
    ↓
更新场景
    ↓
渲染到Canvas
```

### 核心对象关系

```javascript
Scene（场景）
  ├─ Camera（相机）
  ├─ Light（光源）
  │   ├─ AmbientLight（环境光）
  │   ├─ DirectionalLight（方向光）
  │   ├─ PointLight（点光源）
  │   └─ SpotLight（聚光灯）
  └─ Mesh（网格）
      ├─ Geometry（几何体）
      │   ├─ BoxGeometry（立方体）
      │   ├─ SphereGeometry（球体）
      │   └─ ...
      └─ Material（材质）
          ├─ MeshBasicMaterial（基础材质）
          ├─ MeshStandardMaterial（标准材质）
          └─ ...
```

### 绘制旋转立方体

```javascript
// main.js
import * as THREE from 'three';

// 1. 创建场景
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a1a); // 设置背景色

// 2. 创建相机
const camera = new THREE.PerspectiveCamera(
  75,                                      // 视野角度（FOV）
  window.innerWidth / window.innerHeight,  // 宽高比
  0.1,                                     // 近裁剪面
  1000                                     // 远裁剪面
);
camera.position.z = 5; // 相机位置

// 3. 创建渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(window.devicePixelRatio); // 适配高清屏
document.body.appendChild(renderer.domElement);

// 4. 创建几何体（立方体）
const geometry = new THREE.BoxGeometry(1, 1, 1);

// 5. 创建材质
const material = new THREE.MeshBasicMaterial({ 
  color: 0x00ff00,
  wireframe: false  // 线框模式
});

// 6. 创建网格（几何体 + 材质）
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

// 7. 动画循环
function animate() {
  requestAnimationFrame(animate);
  
  // 旋转立方体
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  
  // 渲染场景
  renderer.render(scene, camera);
}

// 8. 响应式处理
window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});

// 启动动画
animate();
```

### 封装Three.js应用类

```javascript
// ThreeApp.js
import * as THREE from 'three';

class ThreeApp {
  constructor(container) {
    this.container = container;
    this.init();
    this.createObjects();
    this.animate();
  }
  
  init() {
    // 场景
    this.scene = new THREE.Scene();
    this.scene.background = new THREE.Color(0x1a1a1a);
    
    // 相机
    this.camera = new THREE.PerspectiveCamera(
      75,
      window.innerWidth / window.innerHeight,
      0.1,
      1000
    );
    this.camera.position.set(0, 0, 5);
    
    // 渲染器
    this.renderer = new THREE.WebGLRenderer({ antialias: true });
    this.renderer.setSize(window.innerWidth, window.innerHeight);
    this.renderer.setPixelRatio(window.devicePixelRatio);
    this.container.appendChild(this.renderer.domElement);
    
    // 响应式
    window.addEventListener('resize', () => this.onResize());
  }
  
  createObjects() {
    // 子类实现
  }
  
  animate() {
    requestAnimationFrame(() => this.animate());
    this.update();
    this.renderer.render(this.scene, this.camera);
  }
  
  update() {
    // 子类实现
  }
  
  onResize() {
    this.camera.aspect = window.innerWidth / window.innerHeight;
    this.camera.updateProjectionMatrix();
    this.renderer.setSize(window.innerWidth, window.innerHeight);
  }
}

// 使用
class MyApp extends ThreeApp {
  createObjects() {
    const geometry = new THREE.BoxGeometry(1, 1, 1);
    const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
    this.cube = new THREE.Mesh(geometry, material);
    this.scene.add(this.cube);
  }
  
  update() {
    this.cube.rotation.x += 0.01;
    this.cube.rotation.y += 0.01;
  }
}

export default ThreeApp;
```

## 光照系统

### 光源类型

```javascript
// 1. 环境光（AmbientLight）- 全局均匀照明
const ambientLight = new THREE.AmbientLight(
  0x404040,  // 颜色
  0.5        // 强度
);
scene.add(ambientLight);

// 2. 方向光（DirectionalLight）- 平行光，类似太阳光
const directionalLight = new THREE.DirectionalLight(0xffffff, 1);
directionalLight.position.set(5, 5, 5);
directionalLight.castShadow = true;  // 投射阴影
scene.add(directionalLight);

// 方向光阴影配置
directionalLight.shadow.mapSize.width = 2048;
directionalLight.shadow.mapSize.height = 2048;
directionalLight.shadow.camera.near = 0.5;
directionalLight.shadow.camera.far = 500;

// 3. 点光源（PointLight）- 从一点向四周发光，类似灯泡
const pointLight = new THREE.PointLight(0xffffff, 1, 100);
pointLight.position.set(0, 3, 0);
pointLight.castShadow = true;
scene.add(pointLight);

// 4. 聚光灯（SpotLight）- 锥形光束
const spotLight = new THREE.SpotLight(0xffffff, 1);
spotLight.position.set(10, 10, 10);
spotLight.angle = Math.PI / 6;      // 光锥角度
spotLight.penumbra = 0.1;           // 半影衰减
spotLight.decay = 2;                // 衰减
spotLight.distance = 100;           // 距离
spotLight.castShadow = true;
scene.add(spotLight);

// 5. 半球光（HemisphereLight）- 模拟天空和地面反射
const hemisphereLight = new THREE.HemisphereLight(
  0xffffbb,  // 天空颜色
  0x080820,  // 地面颜色
  0.5        // 强度
);
scene.add(hemisphereLight);

// 6. 矩形区域光（RectAreaLight）- 需要额外导入
import { RectAreaLightUniformsLib } from 'three/addons/lights/RectAreaLightUniformsLib.js';

rectLight.position.set(0, 5, 0);
```

### 阴影系统

```javascript
// 1. 启用渲染器阴影
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // 柔和阴影

// 阴影类型
THREE.BasicShadowMap       // 基础（性能最好）
THREE.PCFShadowMap         // PCF过滤（默认）
THREE.PCFSoftShadowMap     // 柔和阴影
THREE.VSMShadowMap         // 方差阴影

// 2. 设置光源投射阴影
const light = new THREE.DirectionalLight(0xffffff, 1);
light.castShadow = true;
light.shadow.mapSize.width = 2048;   // 阴影贴图分辨率
light.shadow.mapSize.height = 2048;
light.shadow.camera.near = 0.5;
light.shadow.camera.far = 50;
light.shadow.bias = -0.001;          // 阴影偏移（防止条纹）

// 3. 设置物体投射阴影
mesh.castShadow = true;

// 4. 设置物体接收阴影
ground.receiveShadow = true;

// 完整示例
function setupShadows() {
  // 渲染器
  renderer.shadowMap.enabled = true;
  renderer.shadowMap.type = THREE.PCFSoftShadowMap;
  
  // 光源
  const light = new THREE.DirectionalLight(0xffffff, 1);
  light.position.set(5, 10, 5);
  light.castShadow = true;
  light.shadow.mapSize.set(2048, 2048);
  scene.add(light);
  
  // 立方体（投射阴影）
  const cube = new THREE.Mesh(
    new THREE.BoxGeometry(1, 1, 1),
    new THREE.MeshStandardMaterial({ color: 0x00ff00 })
  );
  cube.castShadow = true;
  cube.position.y = 1;
  scene.add(cube);
  
  // 地面（接收阴影）
  const ground = new THREE.Mesh(
    new THREE.PlaneGeometry(10, 10),
    new THREE.MeshStandardMaterial({ color: 0x808080 })
  );
  ground.receiveShadow = true;
  ground.rotation.x = -Math.PI / 2;
  scene.add(ground);
}
```

```javascript
class StarField {
  constructor(container) {
    this.container = container;
    this.init();
    this.createStars();
    this.animate();
  }
  
  init() {
    this.scene = new THREE.Scene();

    this.renderer.setSize(window.innerWidth, window.innerHeight);
    this.renderer.setPixelRatio(window.devicePixelRatio);
    this.container.appendChild(this.renderer.domElement);
  }
  
  createStars() {
    const count = 10000;
    const geometry = new THREE.BufferGeometry();
    
    const positions = new Float32Array(count * 3);
    const colors = new Float32Array(count * 3);
    const sizes = new Float32Array(count);
    
    for (let i = 0; i < count; i++) {
      // 位置（球形分布）
      const radius = Math.random() * 50 + 10;
      const theta = Math.random() * Math.PI * 2;
      const phi = Math.acos(Math.random() * 2 - 1);
      
      positions[i * 3] = radius * Math.sin(phi) * Math.cos(theta);
      positions[i * 3 + 1] = radius * Math.sin(phi) * Math.sin(theta);
      positions[i * 3 + 2] = radius * Math.cos(phi);
      
      // 颜色（蓝白色调）
      colors[i * 3] = 0.8 + Math.random() * 0.2;
      colors[i * 3 + 1] = 0.8 + Math.random() * 0.2;
      colors[i * 3 + 2] = 1.0;
      
      // 大小
      sizes[i] = Math.random() * 3 + 1;
    }
    
    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));
    geometry.setAttribute('size', new THREE.BufferAttribute(sizes, 1));
    
    // 自定义Shader实现闪烁效果
    const material = new THREE.ShaderMaterial({
      uniforms: {
        time: { value: 0 },
      },
      vertexShader: `
        attribute float size;
        attribute vec3 color;
        varying vec3 vColor;
        uniform float time;
        
        void main() {
          vColor = color;
          vec4 mvPosition = modelViewMatrix * vec4(position, 1.0);
          
          // 闪烁效果
          float twinkle = sin(time + position.x * 10.0) * 0.5 + 0.5;
          gl_PointSize = size * twinkle * (300.0 / -mvPosition.z);
          
          gl_Position = projectionMatrix * mvPosition;
        }
      `,
      fragmentShader: `
        varying vec3 vColor;
        
        void main() {
          // 圆形粒子
          float distance = length(gl_PointCoord - vec2(0.5));
          if (distance > 0.5) discard;
          
          // 边缘柔化
          float alpha = 1.0 - smoothstep(0.3, 0.5, distance);
          
          gl_FragColor = vec4(vColor, alpha);
        }
      `,
      transparent: true,
      depthWrite: false,
      blending: THREE.AdditiveBlending,
    });
    
    this.stars = new THREE.Points(geometry, material);
    this.scene.add(this.stars);
  }
  
  animate() {
    requestAnimationFrame(() => this.animate());
    
    // 旋转星空
    this.stars.rotation.y += 0.0002;
    this.stars.rotation.x += 0.0001;
    
    // 更新时间uniform
    this.stars.material.uniforms.time.value += 0.01;
    
    this.renderer.render(this.scene, this.camera);
  }
}
```

### Q1: Three.js的核心概念有哪些？

**答案：**

Three.js有三个核心要素：**场景（Scene）、相机（Camera）、渲染器（Renderer）**

**1. 场景（Scene）**
- 容器，包含所有3D对象、光源、相机
- 相当于舞台

**2. 相机（Camera）**
- 观察者视角
- 透视相机（PerspectiveCamera）：近大远小，最常用
- 正交相机（OrthographicCamera）：平行投影，无透视

**3. 渲染器（Renderer）**
- 将场景渲染到Canvas
- WebGLRenderer：基于WebGL
- CSS2DRenderer：CSS2D渲染
- CSS3DRenderer：CSS3D渲染

**基础结构：**
```javascript
const scene = new THREE.Scene();
```

### Q3: Three.js与原生WebGL的区别？

**答案：**

| 对比项 | 原生WebGL | Three.js |
|--------|-----------|----------|
| **代码量** | 绘制立方体~300行 | ~30行 |
| **学习曲线** | 陡峭，需要图形学基础 | 平缓，易上手 |
| **着色器** | 必须手写 | 内置材质系统 |
| **开发效率** | 低 | 高 |
| **性能** | 极致优化潜力 | 略有封装损耗 |
| **适用场景** | 特殊效果、性能要求极高 | 通用3D场景 |

**关系：**
```
Three.js（高层封装）
    ↓ 内部使用
WebGL（底层API）
    ↓ 基于
OpenGL ES 2.0/3.0
```

**选型建议：**
- 快速开发、通用场景 → **Three.js**
- 极致性能优化、特殊效果 → **原生WebGL**
- 大规模数据可视化 → **Three.js + 自定义Shader**

**实战经验：**
> "在项目中，我根据场景选择技术方案。通用3D场景使用Three.js快速开发，对于需要自定义渲染效果的部分（如特殊粒子系统），我使用ShaderMaterial编写自定义着色器，既保证开发效率，又实现定制化效果。"

```javascript
renderer.shadowMap.enabled = true;
```

### Q5: 如何加载外部模型？

**答案：**

**推荐格式：GLTF/GLB**

```javascript
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load(
  'model.glb',
  (gltf) => {
    const model = gltf.scene;
    
    // 调整缩放和位置
    model.scale.set(2, 2, 2);
    model.position.set(0, 0, 0);
    
    // 添加到场景
    scene.add(model);
    
    // 处理动画
    if (gltf.animations.length > 0) {
      const mixer = new THREE.AnimationMixer(model);
      const action = mixer.clipAction(gltf.animations[0]);
      action.play();
    }
  },
  (xhr) => {
    // 进度回调
    console.log((xhr.loaded / xhr.total * 100) + '% loaded');
  },
  (error) => {
    console.error('加载失败', error);
  }
);
```

**Draco压缩模型（文件更小）：**

```javascript
import { DRACOLoader } from 'three/addons/loaders/DRACOLoader.js';

const dracoLoader = new DRACOLoader();
dracoLoader.setDecoderPath('draco/');

const gltfLoader = new GLTFLoader();
gltfLoader.setDRACOLoader(dracoLoader);
gltfLoader.load('compressed.glb', (gltf) => {
  scene.add(gltf.scene);
});
```

**模型优化：**

```javascript
// 遍历修改所有材质
model.traverse((child) => {
  if (child.isMesh) {
    child.castShadow = true;
    child.receiveShadow = true;
    
    // 替换材质
    child.material = new THREE.MeshStandardMaterial({
      map: child.material.map,
      metalness: 0.5,
      roughness: 0.5,
    });
  }
});
```

**实战经验：**
> "在产品展示项目中，我们使用Blender导出Draco压缩的GLB模型，文件大小从15MB压缩到3MB。通过LoadingManager统一管理加载进度，显示加载动画，提升用户体验。"

### Q6: 如何实现物体交互（点击、拖拽）？

**答案：**

**使用Raycaster实现点击检测：**

```javascript
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();

window.addEventListener('click', (event) => {
  // 转换为标准化设备坐标
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
  
  // 从相机发射射线
  raycaster.setFromCamera(mouse, camera);
  
  // 检测相交
  const intersects = raycaster.intersectObjects(scene.children);
  
  if (intersects.length > 0) {
    const object = intersects[0].object;
    console.log('点击了:', object.name);
    
    // 高亮效果
    object.material.emissive.set(0x555555);
  }
});
```

**拖拽物体：**

```javascript
import { DragControls } from 'three/addons/controls/DragControls.js';

const objects = [cube1, cube2, cube3];
const dragControls = new DragControls(objects, camera, renderer.domElement);

dragControls.addEventListener('dragstart', (event) => {
  orbitControls.enabled = false;
});

dragControls.addEventListener('dragend', (event) => {
  orbitControls.enabled = true;
});
```

**悬停效果：**

```javascript
let hoveredObject = null;

window.addEventListener('mousemove', (event) => {
  mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
  mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
  
  raycaster.setFromCamera(mouse, camera);
  const intersects = raycaster.intersectObjects(scene.children);
  
  // 恢复之前的物体
  if (hoveredObject) {
    hoveredObject.material.emissive.set(0x000000);
  }
  
  // 高亮当前物体
  if (intersects.length > 0) {
    hoveredObject = intersects[0].object;
    hoveredObject.material.emissive.set(0x333333);
  } else {
    hoveredObject = null;
  }
});
```

> "在产品展示项目中，我实现了完整的交互系统：点击物体显示详情弹窗，鼠标悬停高亮显示，双击切换视角。使用Raycaster进行精确的射线检测，配合CSS2DRenderer渲染HTML标注，实现了流畅的用户体验。"
