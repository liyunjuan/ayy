# 正则表达式核心要点

> 前端面试必备：常用正则及实战案例

## 一、基础语法

### 1.1 创建正则

```javascript
// 方式1：字面量（推荐）
const reg1 = /pattern/flags

// 方式2：构造函数（动态创建）
const reg2 = new RegExp('pattern', 'flags')

// 示例
const reg1 = /hello/i
const reg2 = new RegExp('hello', 'i')
```

### 1.2 修饰符（Flags）

| 修饰符 | 含义 | 示例 |
|-------|------|------|
| `g` | 全局匹配 | `/a/g` 匹配所有 a |
| `i` | 忽略大小写 | `/a/i` 匹配 a 或 A |
| `m` | 多行模式 | `/^a/m` 每行开头匹配 |
| `s` | dotAll 模式 | `/./s` 匹配包括换行符 |
| `u` | Unicode 模式 | `/\u{61}/u` 匹配 a |
| `y` | 粘连模式 | `/a/y` 从 lastIndex 开始匹配 |

```javascript
// 全局匹配
'aaa'.match(/a/)    // ['a']（只匹配第一个）
'aaa'.match(/a/g)   // ['a', 'a', 'a']（匹配所有）

// 忽略大小写
/hello/i.test('HELLO')  // true

// 多行模式
const text = 'line1\nline2'
/^line2/.test(text)    // false
/^line2/m.test(text)   // true
```

## 二、元字符

### 2.1 字符类

| 元字符 | 含义 | 等价 |
|-------|------|------|
| `.` | 任意字符（除换行） | - |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 字母数字下划线 | `[a-zA-Z0-9_]` |
| `\W` | 非字母数字下划线 | `[^a-zA-Z0-9_]` |
| `\s` | 空白字符 | `[ \t\n\r\f\v]` |
| `\S` | 非空白字符 | `[^ \t\n\r\f\v]` |

```javascript
// 示例
/\d/.test('123')      // true
/\d/.test('abc')      // false

/\w+/.exec('hello_123')  // ['hello_123']
/\s+/.exec('a b c')      // [' ']
```

### 2.2 量词

| 量词 | 含义 |
|------|------|
| `*` | 0 次或多次 |
| `+` | 1 次或多次 |
| `?` | 0 次或 1 次 |
| `{n}` | 恰好 n 次 |
| `{n,}` | 至少 n 次 |
| `{n,m}` | n 到 m 次 |

```javascript
// 示例
/\d*/.test('')      // true（0 次）
/\d+/.test('')      // false（至少 1 次）
/\d?/.test('1')     // true（0 或 1 次）

/\d{3}/.test('123')    // true（恰好 3 次）
/\d{2,4}/.test('12')   // true（2 到 4 次）
/\d{2,}/.test('12345') // true（至少 2 次）
```

### 2.3 贪婪 vs 非贪婪

```javascript
// 贪婪匹配（默认）：尽可能多地匹配
const str = '<div>content</div>'
str.match(/<.*>/)   // ['<div>content</div>']（匹配到最后一个 >）

// 非贪婪匹配：尽可能少地匹配（量词后加 ?）
str.match(/<.*?>/)  // ['<div>']（匹配到第一个 >）

// 对比
'aaa'.match(/a+/)   // ['aaa']（贪婪）
'aaa'.match(/a+?/)  // ['a']（非贪婪）
```

### 2.4 位置匹配

| 元字符 | 含义 |
|-------|------|
| `^` | 开头 |
| `$` | 结尾 |
| `\b` | 单词边界 |
| `\B` | 非单词边界 |

```javascript
// 开头和结尾
/^hello/.test('hello world')  // true
/world$/.test('hello world')  // true
/^hello$/.test('hello')       // true（完全匹配）

// 单词边界
/\bhello\b/.test('hello world')  // true
/\bhello\b/.test('helloworld')   // false
/\Bhello\B/.test('ahellob')      // true
```

### 2.5 分组和引用

```javascript
// 分组：()
/(\d{4})-(\d{2})-(\d{2})/.exec('2024-06-24')
// ['2024-06-24', '2024', '06', '24']

// 非捕获分组：(?:)
/(?:\d{4})-(\d{2})/.exec('2024-06-24')
// ['2024-06-24', '06']（第一组不捕获）

// 反向引用：\1 \2
/(\w+)\s\1/.test('hello hello')  // true
/(\w+)\s\1/.test('hello world')  // false

// 命名分组：(?<name>)
const match = /(?<year>\d{4})-(?<month>\d{2})/.exec('2024-06')
match.groups  // { year: '2024', month: '06' }
```

## 三、常用方法

### 3.1 RegExp 方法

```javascript
const reg = /\d+/g

// test：测试是否匹配（返回 boolean）
reg.test('abc123')  // true

// exec：返回匹配结果（返回数组或 null）
const result = reg.exec('abc123def456')
// ['123', index: 3, input: 'abc123def456', groups: undefined]

// ⚠️ 注意：全局模式下，exec 会记住 lastIndex
const reg = /\d+/g
reg.exec('a1b2')  // ['1']
reg.lastIndex     // 2
reg.exec('a1b2')  // ['2']（从 lastIndex 开始）
reg.lastIndex     // 4
reg.exec('a1b2')  // null（没有更多匹配）
reg.lastIndex     // 0（重置）
```

### 3.2 String 方法

```javascript
const str = 'hello world'

// match：匹配（返回数组或 null）
str.match(/\w+/)    // ['hello']（非全局：返回第一个匹配）
str.match(/\w+/g)   // ['hello', 'world']（全局：返回所有匹配）

// matchAll：匹配所有（返回迭代器）⭐ 推荐
const matches = str.matchAll(/\w+/g)
for (const match of matches) {
  console.log(match)
}
// ['hello', index: 0, ...]
// ['world', index: 6, ...]

// search：查找位置（返回索引或 -1）
str.search(/world/)  // 6
str.search(/abc/)    // -1

// replace：替换
str.replace(/world/, 'JS')        // 'hello JS'
str.replace(/o/g, '0')            // 'hell0 w0rld'（全局替换）

// 替换函数
str.replace(/\w+/g, (match) => {
  return match.toUpperCase()
})  // 'HELLO WORLD'

// split：分割
'a,b;c'.split(/[,;]/)  // ['a', 'b', 'c']
```

### 4.3 身份证号

```javascript
// 18 位身份证
const idCardReg = /^[1-9]\d{5}(19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])\d{3}[\dXx]$/

idCardReg.test('110101199001011234')  // true
idCardReg.test('11010119900101123X')  // true
idCardReg.test('110101199013011234')  // false（月份错误）

// 带校验码验证
function validateIdCard(id) {
  if (!idCardReg.test(id)) return false
  
  // 验证校验码
  const weights = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]
  const codes = '10X98765432'
  
  let sum = 0
  for (let i = 0; i < 17; i++) {
    sum += parseInt(id[i]) * weights[i]
  }
  
  const checkCode = codes[sum % 11]
  return checkCode === id[17].toUpperCase()
}
```

### 4.4 URL

```javascript
// 基础版
const urlReg = /^https?:\/\/.+/

// 完整版
const fullUrlReg = /^(https?):\/\/([\w.-]+)(:\d+)?(\/[^\s]*)?(\?[^\s]*)?(#[^\s]*)?$/

const url = 'https://example.com:8080/path/to/page?id=1#section'
const match = url.match(fullUrlReg)
// [
//   'https://example.com:8080/path/to/page?id=1#section',
//   'https',           // 协议
//   'example.com',     // 域名
//   ':8080',           // 端口
//   '/path/to/page',   // 路径
//   '?id=1',           // 查询参数
//   '#section'         // 哈希
// ]

// 提取查询参数
function getUrlParams(url) {
  const params = {}
  url.replace(/[?&]([^=&#]+)=([^&#]*)/g, (_, key, value) => {
    params[key] = decodeURIComponent(value)
  })
  return params
}

getUrlParams('https://example.com?name=John&age=18')
// { name: 'John', age: '18' }
```

### 4.5 密码强度

```javascript
// 8-16 位，必须包含大小写字母、数字
const passwordReg = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d]{8,16}$/

passwordReg.test('Abc12345')   // true
passwordReg.test('abc12345')   // false（缺少大写）
passwordReg.test('ABC12345')   // false（缺少小写）
passwordReg.test('Abcdefgh')   // false（缺少数字）

// 包含特殊字符版本
const strongPasswordReg = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]{8,16}$/

// 密码强度检测
function checkPasswordStrength(password) {
  let strength = 0
  
  if (/[a-z]/.test(password)) strength++  // 小写字母
  if (/[A-Z]/.test(password)) strength++  // 大写字母
  if (/\d/.test(password)) strength++     // 数字
  if (/[@$!%*?&]/.test(password)) strength++  // 特殊字符
  if (password.length >= 8) strength++    // 长度
  
  if (strength <= 2) return '弱'
  if (strength <= 4) return '中'
  return '强'
}
```

### 4.6 金额格式化

```javascript
// 千分位分隔
function formatMoney(num) {
  return String(num).replace(/\B(?=(\d{3})+(?!\d))/g, ',')
}

formatMoney(1234567.89)  // '1,234,567.89'

// 详解：
// \B：非单词边界（数字之间）
// (?=(\d{3})+(?!\d))：正向预查，后面是 3 的倍数个数字

// 提取金额
function extractMoney(str) {
  const match = str.match(/(\d+(?:,\d{3})*(?:\.\d+)?)/)
  return match ? match[1].replace(/,/g, '') : null
}

extractMoney('价格：¥1,234.56')  // '1234.56'
```

### 4.7 HTML 标签处理

```javascript
// 移除 HTML 标签
function stripHtml(html) {
  return html.replace(/<[^>]*>/g, '')

stripHtml('<div>Hello <span>World</span></div>')  // 'Hello World'

// 匹配特定标签
const imgReg = /<img\s+[^>]*src="([^"]*)"[^>]*>/gi

const html = '<img src="a.jpg"> <img src="b.jpg">'
const images = []
let match

while ((match = imgReg.exec(html)) !== null) {
  images.push(match[1])

// 或使用 matchAll（推荐）
const images = [...html.matchAll(imgReg)].map(m => m[1])
```

### 4.8 敏感词过滤

```javascript
// 敏感词替换
function filterWords(text, words) {
  const pattern = new RegExp(words.join('|'), 'gi')
  return text.replace(pattern, match => '*'.repeat(match.length))
}

const sensitiveWords = ['damn', 'fuck', 'shit']
filterWords('This is damn good!', sensitiveWords)
// 'This is **** good!'

// 高亮显示
function highlightWords(text, words) {
  const pattern = new RegExp(`(${words.join('|')})`, 'gi')
  return text.replace(pattern, '<mark>$1</mark>')
}

highlightWords('React and Vue are frameworks', ['React', 'Vue'])
// '<mark>React</mark> and <mark>Vue</mark> are frameworks'
```

## 六、高级技巧

### 6.1 正向预查和反向预查

```javascript
// 正向预查 (?=pattern)：匹配后面是 pattern 的位置
'hello123world'.replace(/\d+(?=world)/, 'X')
// 'helloXworld'（123 后面是 world，所以匹配）

// 负向预查 (?!pattern)：匹配后面不是 pattern 的位置
'hello123world456'.match(/\d+(?!world)/g)
// ['456']（456 后面不是 word）

// 正向回顾 (?<=pattern)：匹配前面是 pattern 的位置
'$100'.replace(/(?<=\$)\d+/, 'X')
// '$X'（100 前面是 $）

// 负向回顾 (?<!pattern)：匹配前面不是 pattern 的位置
'$100 €200'.match(/(?<!\$)\d+/g)
// ['200']（200 前面不是 $）
```

### 6.2 条件匹配

```javascript
// 匹配成对的引号
const quotedReg = /(['"]).*?\1/

quotedReg.test('"hello"')   // true
quotedReg.test("'hello'")   // true
quotedReg.test('"hello\'')  // false（引号不匹配）

// 匹配重复单词
const duplicateReg = /\b(\w+)\s+\1\b/

duplicateReg.test('hello hello')  // true
duplicateReg.test('hello world')  // false
```

### 6.3 提高性能

```javascript
// ❌ 不推荐：回溯陷阱
const badReg = /(a+)+b/
// 'aaaaaaaaaa' 会导致大量回溯，性能极差

// ✅ 推荐：避免嵌套量词
const goodReg = /a+b/

// ❌ 不推荐：贪婪匹配
'<div>content</div>'.match(/<.*>/)
// 匹配整个字符串，性能差

// ✅ 推荐：非贪婪匹配
'<div>content</div>'.match(/<.*?>/)
// 只匹配 <div>，性能好

// 缓存正则对象
// ❌ 不推荐
function validate(str) {
  return /\d+/.test(str)  // 每次调用都创建新正则
}

// ✅ 推荐
const numberReg = /\d+/
function validate(str) {
  return numberReg.test(str)  // 复用正则对象
}
```

## 七、易错点

### 7.1 全局模式的 lastIndex

```javascript
const reg = /\d+/g

reg.test('123')  // true
reg.lastIndex    // 3（记住了位置）

reg.test('123')  // false（从位置 3 开始，没有匹配）
reg.lastIndex    // 0（重置）

reg.test('123')  // true（重新从 0 开始）

// ✅ 解决方案：每次使用前重置
reg.lastIndex = 0
```

### 7.2 点号不匹配换行符

```javascript
const str = 'line1\nline2'

/.+/.test(str)    // true（匹配 line1）
/.+/s.test(str)   // true（匹配整个字符串）

// 如果需要匹配包括换行符，使用 s 修饰符或 [\s\S]
/[\s\S]+/.test(str)  // true
```

### 7.3 转义问题

```javascript
// ❌ 错误：特殊字符没转义
const reg1 = /\d+\.\d+/  // 正确：转义 .
const reg2 = /\d+.\d+/   // 错误：. 匹配任意字符

// 需要转义的字符：. * + ? ^ $ { } ( ) | [ ] \ /
function escapeRegExp(str) {
  return str.replace(/[.*+?^${}()|[\]\\]/g, '\\$&')
}

// 使用
const userInput = 'price: $10.99'
const escaped = escapeRegExp(userInput)
const reg = new RegExp(escaped)
```

### 7.4 反向引用的陷阱

```javascript
// ❌ 错误：反向引用在字符类中无效
/[\1]/.test('1')  // true（\1 被当作普通字符）

// ✅ 正确：反向引用在字符类外
/(\d)\1/.test('11')  // true
/(\d)\1/.test('12')  // false
```

## 八、实用工具函数

```javascript
// 1. 通用验证器
function createValidator(pattern, message) {
  return function(value) {
    if (!pattern.test(value)) {
      return { valid: false, message }
    }
    return { valid: true }
  }
}

const validatePhone = createValidator(
  /^1[3-9]\d{9}$/,
  '手机号格式错误'
)

validatePhone('13812345678')  // { valid: true }
validatePhone('123')          // { valid: false, message: '手机号格式错误' }

// 2. 批量验证
function validate(data, rules) {
  const errors = {}
  
  for (const [key, rule] of Object.entries(rules)) {
    const value = data[key]
    const result = rule(value)
    
    if (!result.valid) {
      errors[key] = result.message
    }
  }
  
  return {
    valid: Object.keys(errors).length === 0,
    errors
  }
}

// 使用
const formData = {
  phone: '138123456',
  email: 'invalid'
}

const rules = {
  phone: createValidator(/^1[3-9]\d{9}$/, '手机号格式错误'),
  email: createValidator(/^[^\s@]+@[^\s@]+\.[^\s@]+$/, '邮箱格式错误')
}

validate(formData, rules)
// {
//   valid: false,
//   errors: {
//     phone: '手机号格式错误',
//     email: '邮箱格式错误'
//   }
// }

// 3. 正则表达式构建器
class RegexBuilder {
  constructor() {
    this.pattern = ''
  }
  
  start() {
    this.pattern += '^'
    return this
  }
  
  end() {
    this.pattern += '$'
    return this
  }
  
  digit(count) {
    this.pattern += count ? `\\d{${count}}` : '\\d+'
    return this
  }
  
  letter(count) {
    this.pattern += count ? `[a-zA-Z]{${count}}` : '[a-zA-Z]+'
    return this
  }
  
  optional(pattern) {
    this.pattern += `(?:${pattern})?`
    return this
  }
  
  build(flags) {
    return new RegExp(this.pattern, flags)
  }
}

// 使用
const phoneReg = new RegexBuilder()
  .start()
  .digit(1)
  .letter(2)
  .digit(8)
  .end()
  .build()
```

### Q1: 手写一个 URL 参数解析函数

```javascript
function parseUrlParams(url) {
  const params = {}
  const queryString = url.split('?')[1] || ''
  
  queryString.replace(/([^=&]+)=([^&]*)/g, (_, key, value) => {
    params[decodeURIComponent(key)] = decodeURIComponent(value)
  })
  
  return params
}

parseUrlParams('https://example.com?name=John&age=18')
// { name: 'John', age: '18' }
```

```javascript
function template(str, data) {
  return str.replace(/\{\{(\w+)\}\}/g, (_, key) => {

  })

template('Hello {{name}}, you are {{age}} years old', {
```

### Q3: 实现千分位格式化

```javascript
function formatNumber(num) {
  return String(num).replace(/\B(?=(\d{3})+(?!\d))/g, ',')
}

formatNumber(1234567.89)  // '1,234,567.89'

// 详解正则：
// \B: 非单词边界（数字之间）
// (?=(\d{3})+(?!\d)): 
//   - (?=...): 正向预查
//   - (\d{3})+: 后面是 3 的倍数个数字
//   - (?!\d): 后面不是数字（确保是最后）
```

## 十、总结

### 核心要点

1. **修饰符**：g 全局、i 忽略大小写、m 多行、s dotAll
2. **元字符**：\d 数字、\w 字母数字、\s 空白、. 任意字符
3. **量词**：* 0+、+ 1+、? 0或1、{n,m} 范围
4. **位置**：^ 开头、$ 结尾、\b 单词边界
5. **分组**：() 捕获、(?:) 非捕获、\1 反向引用
6. **贪婪**：默认贪婪，加 ? 变非贪婪

### 常用正则速查

```javascript
// 手机号
/^1[3-9]\d{9}$/

// 邮箱
/^[^\s@]+@[^\s@]+\.[^\s@]+$/

// 身份证
/^[1-9]\d{5}(19|20)\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\d|3[01])\d{3}[\dXx]$/

// URL
/^https?:\/\/.+/

// 中文
/^[一-龥]+$/

// 日期 YYYY-MM-DD
/^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/
```
