## 🌟 技术亮点速查

### 1. Monorepo 架构

**规模**：
- 3 个前端应用 + 1 个共享层
- 2300+ 文件统一管理
- 共享层代码复用率 **60%**

**优势**：
- ✅ 依赖统一管理，避免版本冲突
- ✅ 代码复用，减少重复代码 60%
- ✅ 原子提交，跨项目修改一个 Commit
- ✅ node_modules 从 2GB 降到 800MB

**技术栈**：
```
Yarn Workspaces + 路径别名 + resolutions 版本锁定
```

---

### 2. 多国家架构

**支持国家**：CN、Indo、Mex、Sea、EU、Esp（6 个）

**三层控制**：
```
第一层：国家判断（环境变量 + 域名 + URL 参数）
第二层：路由控制（Meta businessCode + 路由守卫）
第三层：配置中心（运行时动态加载）
第四层：国际化（自动切换语言，支持 5 种语言）
```

**关键价值**：
- ✅ 一套代码支持 6 个国家
- ✅ 配置热更新，无需重新部署
- ✅ 路由自动拦截，防止误访问

### 4. 实时通信双通道

**架构**：
```
┌─────────────────────────────────┐
│         YChat 工作台             │
├─────────────────────────────────┤
│  WebSocket          WebRTC      │
│  (STOMP)           (JsSIP)      │
│     ↓                 ↓          │
│  IM 在线聊天      电话通信       │
└─────────────────────────────────┘
```

**WebSocket 优化**：
- **指数退避重连**：1s → 1.5s → 2.25s → ... → 30s
- **消息队列缓存**：断线期间消息不丢失
- **心跳机制**：30 秒发一次，60 秒超时
- **重连成功率**：80% → **98%**
- **消息丢失率**：5% → **0.1%**

**WebRTC 优化**：
- **跨 Tab 冲突解决**：Broadcast Channel 状态同步
- **通话质量监控**：实时采集 RTCStatsReport
- **音频处理**：Wavesurfer.js + 降噪算法

### 6. 性能优化

**首屏加载优化**（4.5s → 1.5s）：
```
1. 路由懒加载：拆分 10+ chunk          -30%
2. Ant Design Vue 按需引入            -40%
3. 代码分割：vendors 单独缓存         -15%
4. 预加载关键资源：preload/prefetch   -10%
5. 图片优化：CDN + WebP + 懒加载      -5%
```

**长列表优化**：
```
1. 虚拟滚动：RecycleScroller          DOM: 1000+ → 20
2. 分页加载：首屏只加载 50 条          内存: 500MB → 80MB
3. 图片懒加载：vue-lazyload            FPS: 20fps → 60fps
4. 防抖/节流：throttle 100ms
```

**Bundle 优化**：
```
优化前：3.2MB
优化后：1.1MB（-65%）

chunk-vendors.js: 1.2MB → 450KB
app.js: 1.5MB → 420KB
其他 chunks: 500KB → 230KB
```

## 🎯 面试应对策略

### 1. 开场破冰

**面试官**："介绍一下你最近的项目。"

**回答策略**：
1. 先说**项目定位**和**业务价值**（30 秒）
2. 再说**技术架构**和**规模**（30 秒）
3. 重点说**你负责的模块**和**成果**（1 分钟）
4. 留悬念，引导面试官提问

---

### 2. 技术深挖

**面试官**："你说首屏优化到 1.5 秒，具体怎么做的？"

**回答策略**：
1. **先说优化前的问题**（指标 + 痛点）
2. **列举优化措施**（5 个方向）
3. **重点展开 1-2 个措施**（代码示例）
4. **给出优化后的数据**（对比）
5. **说明监控手段**（如何保证持续优化）

---

### 3. 难点挑战

**面试官**："遇到过最大的技术难点是什么？"

**回答策略**：用 **STAR 法则**
1. **S**ituation：遇到什么问题？（背景 + 痛点）
2. **T**ask：你的任务是什么？（目标）
3. **A**ction：你采取了什么行动？（方案 + 实现）
4. **R**esult：结果如何？（数据 + 价值）

**推荐案例**：
- WebSocket 断线重连（指数退避 + 消息队列）
- YTalk 跨 Tab 冲突（Broadcast Channel）
- 长列表性能（虚拟滚动）

---

### 4. 架构设计

**面试官**："多国家架构是如何设计的？"

**回答策略**：
1. **先说挑战**：6 个国家，功能差异大
2. **给出整体方案**：三层控制（路由 + 配置 + i18n）
3. **展开每一层**：如何实现 + 代码示例
4. **强调价值**：一套代码 6 国家，易维护
5. **说明扩展性**：新增国家只需配置

---

### 5. 团队协作

**面试官**："如何与后端协作？"

**回答策略**：
1. **协作流程**：需求评审 → 接口设计 → Mock 开发 → 联调
2. **协作工具**：Swagger、Mock.js、Postman
3. **沟通方式**：定期同步、文档共享
4. **举例说明**：某次接口联调的完整过程
