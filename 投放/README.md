```
案例1：定向选择器优化

- 结果：选择耗时 5s → 0.5s

案例2：监控大盘优化
- 问题：100个图表同时渲染崩溃
- 方案：懒加载 + 虚拟列表 + Web Worker
- 结果：内存占用 2GB → 200MB
```

## 🚀 快速开始

### 1. 核心概念速查

| 术语 | 含义 | 示例 |
|------|------|------|
| **CPM** | Cost Per Mille（千次曝光成本） | 1000次曝光花10元 = CPM 10元 |
| **CPC** | Cost Per Click（单次点击成本） | 100次点击花200元 = CPC 2元 |
| **CPA** | Cost Per Action（单次转化成本） | 10次注册花500元 = CPA 50元 |
| **CTR** | Click Through Rate（点击率） | 1000曝光100点击 = CTR 10% |
| **CVR** | Conversion Rate（转化率） | 100点击10转化 = CVR 10% |
| **ROI** | Return On Investment（投资回报率） | 花1000赚2000 = ROI 100% |

### 2. 投放流程

```
创建广告计划
    ↓
配置定向条件（地域、年龄、兴趣）
    ↓
设置预算和出价
    ↓
上传创意素材
    ↓
提交审核
    ↓
审核通过 → 开始投放
    ↓
实时监控数据
    ↓
数据分析 → 调整优化
```

### 3. 主流广告平台

| 平台 | 公司 | 特点 |
|------|------|------|
| **巨量引擎** | 字节跳动 | 抖音、头条流量 |
| **腾讯广告** | 腾讯 | 微信、QQ流量 |
| **阿里妈妈** | 阿里 | 淘宝、天猫流量 |
| **百度推广** | 百度 | 搜索引擎流量 |
| **快手磁力引擎** | 快手 | 短视频流量 |
